# PDF 요약 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PDF를 올리면 OpenRouter 모델이 한국어로 요약(한줄요약·핵심개념·정의된용어·정의된수식)해 돌려주는 Next.js 웹앱을 만들고, 깃 저장소에 푸시한다.

**Architecture:** Next.js App Router 한 페이지 + 서버 라우트 하나. 브라우저는 파일만 보내고, 서버가 PDF에서 글자를 뽑아 OpenRouter를 부른다. 1차 모델이 어떤 이유로든 실패하면 폴백 모델로 딱 한 번 더 시도하고, 둘 다 실패하면 시도 기록을 그대로 돌려준다. 순수 함수(설정 읽기, 글자 뽑기, 모델 호출, 응답 검증)를 `src/lib/`에 모아 라우트는 얇게 유지한다.

**Tech Stack:** Next.js 16 (App Router), TypeScript, Tailwind CSS, Node 26 LTS, `unpdf`, Vitest

**Spec:** `docs/superpowers/specs/2026-11-19-pdf-요약-앱-design.md`

## Global Constraints

- Node 26.13.1 LTS, npm 11.20.0. 이미 열린 터미널은 PATH가 낡았으므로 명령 전에 PATH를 다시 읽힌다.
- 파일·폴더 이름은 영어. 주석·문서·화면 글·커밋 메시지는 한국어. 직접 만든 함수·변수명은 한국어. 프레임워크가 정한 이름(`page.tsx`, `route.ts`, `POST`, `useState`)은 그대로.
- 모든 파일은 UTF-8.
- 모델 이름을 코드에 박지 않는다. 전부 환경변수로 읽는다.
- 키를 로그에 찍지 않는다. 요청 헤더도 찍지 않는다. 서버 로그는 `[summarize]`로 시작하는 줄만 남긴다.
- `.env`는 커밋 금지. `.env.example`만 커밋한다.
- 업로드 파일은 메모리에서만 다룬다. 디스크에 쓰지 않는다.
- 파일 크기 상한 4MB (`4 * 1024 * 1024`).
- `MAX_CHARS` 기본값 `40000`.
- `OPENROUTER_TIMEOUT_MS` 기본값 `40000`, `OPENROUTER_FALLBACK_TIMEOUT_MS` 기본값 `50000`.
- 브라우저 쪽 요청 중단 시계는 115초 (`115000`).
- 요약 API 라우트는 `export const maxDuration = 120`.
- `.env.example`의 `OPENROUTER_FALLBACK_MODEL`은 **빈 값**으로 둔다. 어떤 무료 모델이 살아 있는지는 계정마다 다르므로 지어내지 않는다.
- 실패를 성공처럼 보이게 하지 않는다. 요약이 비면 실패다.

## Review Focus

사양이 함의하지만 어느 작업의 테스트도 직접 건드리지 않는, 사람을 물 가능성이 높은 입력들. 각 줄의 테스트는 해당 코드를 가진 작업에 넣었다.

1. **PDF가 아닌 파일을 PDF로 위장해 올린 경우** — 확장자만 보면 통과한다. 글자 추출이 예외를 던지므로 500이 아니라 400과 한국어 설명이 나와야 한다. → 작업 3
2. **모델이 ```json 울타리로 감싸 응답한 경우** — 무료 모델에서 흔하다. 파싱이 깨지면 멀쩡한 요약을 실패로 처리한다. → 작업 4
3. **모델이 JSON은 맞지만 `핵심개념`을 문자열 배열로 보낸 경우** — 스키마가 어긋나면 화면이 `undefined`를 그린다. 검증에서 걸러 폴백으로 넘겨야 한다. → 작업 4
4. **`정의된수식`이 빈 배열인 경우** — 수식 없는 문서가 대부분이다. 빈 배열을 실패로 치면 멀쩡한 요약이 매번 폴백으로 샌다. → 작업 4
5. **폴백 모델이 설정되지 않은 경우** — `.env.example`이 빈 값으로 나가므로 초기 상태가 바로 이것이다. 1차 실패 시 폴백 없이 즉시 시도 기록을 돌려줘야 한다. → 작업 5

import { 글자뽑기 } from "../src/lib/pdf-text";

describe("글자뽑기", () => {

    expect(결과.쓸글자).toContain("테스트 문서");
    expect(결과.잘림).toBe(false);
    expect(결과.전체글자수).toBeGreaterThan(0);

    expect(결과.쓸글자.length).toBe(5);
    expect(결과.잘림).toBe(true);
    expect(결과.전체글자수).toBeGreaterThan(5);
  });

  it("글자가 없으면 글자없음을 던진다", async () => {
    await expect(글자뽑기(읽기("empty.pdf"), 40000)).rejects.toThrow("글자없음");
  });

  // Review Focus 1: PDF로 위장한 파일
  it("PDF가 아니면 PDF아님을 던진다", async () => {
    await expect(글자뽑기(읽기("not-a-pdf.pdf"), 40000)).rejects.toThrow("PDF아님");
  });
});

### 작업 4: 모델 응답 검증

**Files:**
- Create: `src/lib/validate.ts`
- Test: `tests/validate.test.ts`

**Interfaces:**
- Consumes: 없음
- Produces:
  ```ts
  export type 요약 = {
    한줄요약: string;
    핵심개념: { 이름: string; 설명: string }[];
    정의된용어: { 용어: string; 뜻: string }[];
    정의된수식: { 수식: string; 뜻: string }[];
  };
  export function 요약파싱(원문: string): 요약;
  ```
  파싱이나 스키마 검증에 실패하면 `Error("요약형식오류")`를 던진다.

- [ ] **Step 1: 실패하는 테스트 작성**

```ts
import { describe, it, expect } from "vitest";
import { 요약파싱 } from "../src/lib/validate";

const 온전한요약 = {
  한줄요약: "이 문서는 서브에이전트를 다룬다.",
  핵심개념: [{ 이름: "서브에이전트", 설명: "역할을 나눈 에이전트" }],
  정의된용어: [{ 용어: "PRD", 뜻: "제품 요구사항 문서" }],
  정의된수식: [],
};

describe("요약파싱", () => {
  it("순수 JSON을 읽는다", () => {
    expect(요약파싱(JSON.stringify(온전한요약)).한줄요약).toBe("이 문서는 서브에이전트를 다룬다.");
  });

  // Review Focus 2: ```json 울타리
  it("```json 울타리를 벗겨낸다", () => {
    const 원문 = "```json\n" + JSON.stringify(온전한요약) + "\n```";
    expect(요약파싱(원문).핵심개념).toHaveLength(1);
  });

  // Review Focus 4: 빈 배열은 정상
  it("정의된수식이 비어도 성공이다", () => {
    expect(요약파싱(JSON.stringify(온전한요약)).정의된수식).toEqual([]);
  });

  // Review Focus 3: 스키마 어긋남
  it("핵심개념이 문자열 배열이면 던진다", () => {
    const 어긋남 = { ...온전한요약, 핵심개념: ["서브에이전트"] };
    expect(() => 요약파싱(JSON.stringify(어긋남))).toThrow("요약형식오류");
  });

  it("한줄요약이 비면 던진다", () => {
    const 빈것 = { ...온전한요약, 한줄요약: "  " };
    expect(() => 요약파싱(JSON.stringify(빈것))).toThrow("요약형식오류");
  });

  it("핵심개념이 0개면 던진다", () => {
    const 빈것 = { ...온전한요약, 핵심개념: [] };
    expect(() => 요약파싱(JSON.stringify(빈것))).toThrow("요약형식오류");
  });

  it("JSON이 아니면 던진다", () => {
    expect(() => 요약파싱("죄송합니다 요약할 수 없습니다")).toThrow("요약형식오류");
  });
});
```
